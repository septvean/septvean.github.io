    07764 计量学基础 知识点总结 (题库)

    一、计量学基础（测量科学）

    1. 基本概念

    术语 定义 题库要点
    测量 确定被测量值的实验过程 -
    量值 由数值和单位组成的表达（如 5.2 kg） 数值用阿拉伯数字，一般不用分数（判断题：❌“可用分数”是错误的）
    真值 被测量的客观实际值（理想值，不可知） -
    误差 测量结果 – 真值（不可知） 不能按表示方法分为随机/系统误差（判断题：❌）
    ✓ 正确分类：系统误差、随机误差、粗大误差（按来源/性质）
    偏差 测量值 – 标称值（如量具偏差 = 实际值 – 标称值）✅
    不确定度 表征合理赋予被测量之值的分散性的参数 ✅ 定义题；用标准差或其倍数表示

    ✅ 随机误差 = 误差 – 系统误差（判断题正确）
    ❌ “误差越大，不确定度越大”——错误！不确定度反映可信区间大小，与单次误差无直接关系。

    2. 测量不确定度

    • 定义：与测量结果相联系的参数，表征被测量值的分散性（ISO定义）
    • 表示方式：
      • 标准不确定度（u）：用标准差表示
      • 扩展不确定度（U = k·u）：k 通常取 2（置信水平≈95%）
    • 有效数字：不确定度一般取 1~2 位有效数字 ✅
    • 均匀分布处理：若分散区间为 ±b（总宽 2b），则标准不确定度 = b / √3

      ⚠️ 题库答案有误： “已知分散区间为 b，呈均匀分布，则标准不确定度为 b/2” ❌ 正确应为：u = b / √3（若 b 为半宽）或 u = (区间宽度) / (2√3) 题库中“b”若指全宽，则 u = b / (2√3) ≈ b/3.46；绝非 b/2。 建议以标准公式为准。

    3. 测量仪器性能指标

    指标 含义
    准确度 测量结果接近真值的能力（含系统+随机误差）✅
    精密度（Precision） 多次测量结果相互接近的程度（仅反映随机误差）
    正确度（Trueness） 测量均值接近真值的程度（反映系统误差）
    稳定性 计量特性随时间保持恒定的能力 ✅
    测量区间（Measuring Interval） 在规定条件下，仪器能测量出的一组同类量的量值范围 ✅
    校准测量能力 实验室能提供给用户的最高校准水平，用 k=2 的扩展不确定度表示 ✅

    ✅ 准确度 ≠ 精密度；准确度高 ⇒ 正确度 + 精密度均高

    4. 计量单位与SI单位制

    • SI 基本单位（7个）：

      • 长度：m
      • 质量：kg（不是 m）
      • 时间：s
      • 电流：A ✅
      • 热力学温度：K（不是 ℃）
      • 物质的量：mol（不是 mm）
      • 发光强度：cd

    • 单位符号规范：

      • 比热容：J/(kg·K) ✅（注意中间点或空格）
      • 力矩：N·m（可称“牛顿米”，但符号为 N·m）
      • 面积：2000 m² 不能写为“2千米”（千米是长度单位）❌

    ✅ “比热容单位为 J/(kgK)” 是题库认可的简写形式（虽规范应有间隔，但常接受）

    5. 计量法规与体系

    项目 内容
    《中华人民共和国计量法》 1986年7月1日正式实施 ✅
    国家计量基准 由国家计量行政部门（市场监管总局）组织建立和批准 ✅
    型式批准 承认计量器具型式符合法定要求的决定 ✅
    强制检定 必须由法定计量检定机构执行，企业不能自行检定 ❌
    计量检定员 须经考核合格、持证上岗，非所有从事者都称“检定员” ❌

    ❌ “我国法定计量单位包括9个SI基本单位”——错误！
    SI有7个基本单位，我国法定单位 = SI单位 + 国家选定的非SI单位（如吨、升、公顷等）

    6. 世界计量日

    • 1999年第21届国际计量大会决定：将 5月20日（1875年《米制公约》签署日）定为 世界计量日 ✅

    二、计量经济学基础（题库重点）

    注：本部分虽名“计量学基础”，但题库大量涉及计量经济学内容，需单独梳理。

    1. 数据类型

    类型 定义 题库答案
    横截面数据 同一时点，不同个体的相同指标数据 ✅ 如：2025年各省GDP
    时间序列数据 同一对象，不同时点的相同指标数据 ✅ 如：中国2000–2024年GDP
    混合数据（面板） 两者结合 未考

    2. 变量分类

    分类角度 变量类型 定义 题库要点
    因果关系 解释变量（自变量）
    被解释变量（因变量）    		 ✅ 多选题
    模型内生性 内生变量 由模型内部决定，具随机性 -
    外生变量 由模型外部决定，影响内生变量 ✅ 判断题有误：
    “外生变量由外部决定、影响内生变量” ✓
    但题库单选题说“外生变量是受其他变量影响的随机变量” ❌（这实际是内生变量！）
    题库此处答案错误，应为 A. 内生变量
    滞后变量 内生或外生变量的过去值 -
    前定变量 外生变量 + 滞后内生变量（即非当前随机变量）✅

    ⚠️ 题库单选题错误：
    “由模型内部因素决定、受其他变量影响的随机变量” -> 这是内生变量，非外生变量。
    正确答案应为 A. 内生变量，但题库标答为 B（外生变量）-> 需纠正。

    3. 计量经济模型类型

    • 微观计量模型：描述微观主体（家庭、企业）行为 ✅
    • 宏观计量模型：描述国家/地区总量关系
    • 理论 vs 应用模型：前者重机制，后者重实证

    4. 经典线性回归模型（CLRM）假设

    对模型 ( Y = \beta_0 + \beta_1 X + u )，经典假设包括：

    1. E(u) = 0（零均值）
    2. Var(u) = σ²（同方差）
    3. Cov(u_i，u_j) = 0（无自相关）
    4. X 与 u 不相关（解释变量外生）
    5. u ~ N(0，σ²)（正态性，用于小样本推断）

    ✅ 满足假设 ⇒ OLS估计量具 线性、无偏性、有效性（BLUE）
    ✅ 多选题中 A、B、C、D 均为正确假设

    5. 回归分析核心概念

    概念 定义 公式/性质
    总变差（TSS） ( \sum (Y_i - \bar{Y})^2 ) = RSS + ESS
    回归平方和（ESS） 回归值与均值的离差平方和 ✅
    解释变量引起的变差 ✅    		 = TSS – RSS
    剩余变差（RSS） 实际值与回归值的离差平方和 ✅
    回归未解释的部分 ✅
    随机因素引起的变差 ✅    		 -
    决定系数（R²） ESS / TSS 衡量拟合优度
    调整R²（(\bar{R}^2)） < R² ✅，可能为负 ✅ 惩罚变量过多
    F检验 检验模型整体显著性 ( F = \frac{ESS/k}{RSS/(n-k-1)} ) ✅

    ✅ 异方差常见于横截面数据（如家庭收入 vs 消费）✅

    6. 非线性模型线性化方法

    • 直接置换法（如令 Z = 1/X）
    • 对数变换法（如双对数模型 lnY = a + b lnX）
    • （级数展开、Box-Cox 等也有效，但题库仅选前两者）

    7. 计量经济模型应用

    • 结构分析（弹性、乘数）
    • 经济预测
    • 政策评价（模拟政策效果）
    • 检验和发展经济理论

    三、其他判断题重点澄清

    题干 正误 说明
    “按误差表示方法分：随机、系统误差” ❌ 应按性质/来源分，非“表示方法”
    “计量要求由计量管理者提出” ❌ 应由顾客、法规、产品要求等提出
    “设计、工艺、测量基准应一致，以工艺基准为准” ❌ 应尽可能以设计基准为准（保证功能）
    “我国法定单位含9个SI基本单位” ❌ SI只有7个基本单位

    ✅ 总结：两大知识板块对照

    维度 计量学（测量科学） 计量经济学
    核心 准确测量、单位统一、误差控制 经济关系建模、参数估计、假设检验
    关键词 不确定度、SI单位、校准、检定、《计量法》 回归、内生变量、OLS、R²、F检验
    法规 《计量法》（1986.7.1） 无专门法，依赖统计规范
    国际日 世界计量日（5月20日，1999年确立） 无

    ⚠️ 题库错误修正汇总

    1. “分散区间为 b 的均匀分布，标准不确定度 = b/2” -> ❌

      正确：u = b / √3（若 b 为半宽）

    2. “外生变量是由模型内部决定的随机变量” -> ❌

      正确：这是内生变量；外生变量由模型外部决定

    3. “定距测量可做乘除”（虽属前一科目，但逻辑一致）-> ❌

      只有定比测量可做乘除
